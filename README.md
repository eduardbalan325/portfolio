# Eduard Balan — Portfolio

A modern, professional portfolio website built with React, TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Customize

- **Content**: Edit `src/data/portfolio.ts` to update resume information.
- **Links**: Update LinkedIn and GitHub URLs in `src/data/portfolio.ts`.
